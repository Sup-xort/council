# SWITCH 리디자인 핸드오프

`index.html` 에 옮길 새 디자인(5번안 확정본). 기준 화면은 iPhone 17 Pro, 402×874pt.

- `screens/` — 라이트 모드 화면 전체 길이. 로비, QR 대여 완료, 공지(블록 전부 / 본문만), 행사 상세 + 신청서
- `theme/` — 같은 화면을 한 화면 높이(874)로 자른 것. `dark`·`glass` 두 값으로 라이트/다크, 유리/불투명 탭바를 바꾼다. 색 토큰의 원본은 이쪽 파일 맨 아래 `LIGHT` / `DARK` 객체

`.dc.html` 은 Claude 디자인 캔버스 형식이라 브라우저로 그냥 열면 안 그려진다. 레이아웃·수치·색의 참조용으로만 읽는다. 데이터(이름, 날짜, 신청 인원)는 전부 예시고, `[ ]` 로 감싼 건 아직 정해지지 않은 값이다.

## 기능 범위

화면 구성과 동작은 지금 `index.html` 그대로다. 새로 생기는 건 아래 세 가지뿐이고, 셋 다 서버 작업이 필요하다 (맨 아래 「서버」).

1. 로비 맨 위 공지·행사 배너 캐러셀
2. 공지 상세 화면
3. 행사 신청 인원 게이지 (로비 행사 카드, 행사 상세)

## 색 토큰

지금 `:root` 의 `--bg --sheet --ink …` 를 아래로 바꾼다. 다크는 지금처럼 `@media (prefers-color-scheme: dark)` 로 덮는다.

| 토큰 | 라이트 | 다크 | 쓰는 곳 |
|---|---|---|---|
| `--bg` | `#F0F7FB` | `#0D1215` | 페이지 바탕 |
| `--card` | `#FFFFFF` | `#182025` | 카드 |
| `--fill` | `#F0F7FB` | `#222B31` | 빈 예약 칸, 입력칸, 선택 안 된 칩, 이미지 자리 |
| `--ink` | `#1D1D1F` | `#F2F5F7` | 본문, 주 버튼 배경, 내 예약, 오늘 날짜 |
| `--on-ink` | `#FFFFFF` | `#0D1215` | `--ink` 배경 위 글자 |
| `--sub` | `#6E6E73` | `#9AA3A9` | 보조 글자 |
| `--line` | `rgba(0,0,0,.06)` | `rgba(255,255,255,.08)` | 구분선 |
| `--tint` | `rgba(0,0,0,.06)` | `rgba(255,255,255,.1)` | 보조 버튼, 세그먼트 바탕, 활성 탭 |
| `--track` | `rgba(0,0,0,.07)` | `rgba(255,255,255,.12)` | 게이지 바탕 |
| `--busy` | `#C4E4F4` | `#35596B` | 다른 사람 예약 칸, QR 완료 원, 신청 완료 박스 |
| `--busy-ink` | `#1D1D1F` | `#F2F5F7` | `--busy` 위 글자 |
| `--req` | `#B3261E` | `#F2B8B5` | 필수 항목 별표 |

대비(흰 카드 기준): `--sub` 4.7:1 (연하늘 바탕 위), 다크 카드 위 `--sub` 약 6.3:1, `--busy` 다크 위 흰 글자 약 6.9:1.

## 화면별

### 헤더
높이 52, 아래 1px `--line`. 왼쪽 `SWITCH` 17/600 (로고 장식 없음), 오른쪽 이름 + 로그아웃(`--sub`). 하위 화면은 왼쪽이 `‹ 공지` / `‹ 행사` 같은 뒤로가기.

### 로비 (`screens/lobby`)
1. 배너 캐러셀 — 흰 카드 높이 196, 한 장씩. 분류(공지 / 행사 · 모집 중) 13 `--sub`, 제목, 한 줄 설명, 아래 `자세히 보기 ›` 링크. 아래 점 3개(7px, 활성 `--ink`, 나머지 `rgba(0,0,0,.2)`), 각 점은 24×44 버튼. 배경색은 장마다 바꾸지 않는다
2. 날짜(13 `--sub`) + `세미나실`(32)
3. 세그먼트(세미나실 1/2) + 원형 버튼 `‹` `오늘` `›` (44, `--tint`)
4. 주간 표 — 흰 카드 안. 열 `30px + 7칸`, 칸 높이 32, 간격 3. 상태: 빈 칸 `--fill` 버튼 / 지난 시간 투명 / 다른 사람 `--busy` + 마스킹 이름 10px / 내 예약 `--ink` + 「내 예약」. 오늘 날짜는 지름 28 `--ink` 원. 표 아래 범례 3개
5. `행사` + 흰 카드 하나에 행사들을 구분선으로 나열. 행마다 상태·마감, 제목, 일시, 게이지, `참여 신청`(주 버튼) · `자세히 보기`. 마감된 행사는 한 줄로 접는다

### 행사 게이지
`38명 신청` (숫자만 `--ink` 600) ··· `정원 60명`, 아래 높이 6(상세는 8) 막대, 채움 `--ink`, 바탕 `--track`. 행사 상세에선 큰 숫자 30/700 + `/ 정원 60명` + 오른쪽 `22자리 남음`. 정원이 없는 행사는 막대 없이 `N명 신청` 만.

### 공지 상세 (`screens/notice-full`, `notice-plain`)
항상: 분류 칩 · 날짜 · 작성자 → 제목 → 본문 카드 → 이전/다음 글.
있을 때만: 핵심 정보(일시/장소/대상 같은 이름-값 줄) · 첨부 목록 · 연결된 행사(게이지 + `신청하러 가기`).
본문 블록: 문단, 소제목 18/600, 목록, 이미지(16:10, 모서리 14) + 설명, 강조 박스(`--fill`, 모서리 14), 링크(밑줄).

### 행사 상세 + 신청서 (`screens/event`)
상태 배지 + `마감까지 N일` → 제목 → 게이지 카드 → 정보 카드(일시/장소/신청 마감) → 설명 + `공지 전문 보기 ›` → 신청서 카드.
신청서: 신청자(이름·학번, 계정에서 자동, `--fill` 박스) → 지금의 항목 타입을 그대로 그린다:
- `select` → 2열 칩 버튼(높이 48, 선택 `--ink`) — 드롭다운 대신
- `text` → 높이 48 입력칸 `--fill`
- `checkbox` → 22px 체크박스 + 문구
필수 표시는 `*` `--req`. 필수를 다 채우기 전엔 버튼이 `필수 항목을 채워 주세요`(비활성), 채우면 `참여 신청`. 신청 후엔 `--busy` 박스 「신청됐어요. 마감 전까지 고칠 수 있어요.」 + `신청 내용 수정`.

### QR 대여 완료 (`screens/qr-borrowed`)
가운데 정렬. 지름 76 `--busy` 원 + 체크, `대여 완료` 30/700, 물품명 19/500, 안내 15 `--sub`, `내 대여 보기` 주 버튼(높이 50, 전체 폭). 반납·사용중·오류도 같은 틀에 아이콘과 문구만 바꾼다.

## 하단 탭바 (`theme/`)

유리 바로 바꾼다. 화면 아래에서 20, 좌우 16 띄운 알약(모서리 32, 안쪽 6), 탭 4칸 높이 52, 활성 탭은 `--tint` 알약 + `--ink`, 나머지 탭 글자는 아래 `탭 글자` 색.

| | 라이트 | 다크 |
|---|---|---|
| 바탕 | `rgba(255,255,255,.72)` | `rgba(36,44,50,.85)` |
| 테두리 | `1px rgba(255,255,255,.75)` | `1px rgba(255,255,255,.12)` |
| 그림자 | `0 10px 30px rgba(0,0,0,.12), inset 0 1px 0 rgba(255,255,255,.9)` | `0 10px 30px rgba(0,0,0,.5), inset 0 1px 0 rgba(255,255,255,.1)` |
| 탭 글자 | `#48484D` | `#AEB6BB` |
| 흐림 | `backdrop-filter: blur(24px) saturate(180%)` + `-webkit-` 접두사 | 같음 |

캔버스 시안(`theme/`)은 라이트 58% · 다크 55% 로 그려져 있는데, 이 값이면 바 뒤로 검정 버튼(라이트)이나 흰 칸(다크)이 지나갈 때 탭 글자 대비가 2.5:1 / 1.8:1 까지 떨어진다(블러 없이 색만 겹친 계산). 위 표의 72% + `#48484D`(약 5.0:1), 85%(약 4.6:1)가 그걸 막는 값이다 — 실기기 확인은 아직.

바가 콘텐츠를 가리지 않게 `main` 아래 여백을 `calc(20px + 64px + 24px + env(safe-area-inset-bottom))` 이상으로.

## 서버 (`council.py`)

| 무엇 | 왜 |
|---|---|
| 공지 테이블 — 분류, 제목, 본문, 핵심 정보(이름-값 목록), 첨부, 연결 행사 id, 로비 배너 표시 여부, 작성자, 작성일 | 공지 상세·배너. 지금은 행사만 있다 |

## 정해지지 않은 것

- 행사 장소, 문의 채널, 첨부파일 이름·크기, 출범 인사말 — 시안에서 `[ ]`
- 공지 분류 이름 목록 (시안: 행사 / 안내)
- 다크 탭바를 85% 유리로 갈지 불투명으로 갈지
